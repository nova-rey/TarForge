# TarForge Bible

This document serves as the evolving historical log of architectural decisions and design justification for TarForge.  
It must remain **additive only**.  
Entries are appended at each checkpoint.

---

## Phase 0 — Initialization

TarForge repository created and documentation scaffolding established.  
Initial project intent defined: TarForge is a deterministic packaging utility whose primary responsibility is transforming a user-provided root filesystem directory into a reproducible Screaming Penguin–compatible tarball.  
No runtime behavior exists at this stage.  
Future phases will expand functionality, but the initial conceptual boundaries and intended-use constraints are established here.
