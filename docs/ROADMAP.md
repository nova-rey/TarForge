# TarForge Roadmap (Draft Skeleton)

This is a preliminary roadmap structure.  
Phase definitions will be expanded in future checkpoints.

---

## Phase 0 — Documentation Scaffolding  
*Status: Complete*  
Initialize docs, Bible, design philosophy, and entrypoint metadata.

## Phase 1 — Core Packaging Engine  
Implement deterministic tarball creation (directory walk, exclusion rules, normalization, manifest output).

## Phase 2 — Configuration Schema  
Define YAML configuration for packaging jobs and output artifact definitions.

## Phase 3 — Validation Utilities  
Rootfs validation, sanity checks, and input contract enforcement.

## Phase 4 — Integration Layer  
Screaming Penguin integration, CI scripts, and artifact pipelines.

## Phase 5 — Advanced Features  
Compression tuning, multi-architecture support, plugin hooks, optional QEMU capture integration.

---

This roadmap will evolve as TarForge matures.
